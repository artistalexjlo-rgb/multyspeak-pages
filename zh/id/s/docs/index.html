证件管理：在印度尼西亚实际是怎么运作的 — 第一手

来自真实经验

规定自2026年6月1日起，所有印尼公司（PT）必须通过SABH/AHU系统向司法部提交年度报告。2025财年的截止日期为2026年6月30日。不合规将导致书面警告，并可能暂停对AHU系统的访问，从而导致无法更改公司结构或董事。要求包括财务报表、活动报告、CSR报告（资源部门）、监督报告以及董事/专员薪酬数据。
✓ 1 条反馈 来自聊天群
规定办理家庭 KITAS（配偶为印尼公民）时，流程通常涉及根据配偶的居民身份证（KTP）注册地获取居住证明（SKTT）。如果配偶的 KTP 在雅加达注册，初步注册可能需要在当地进行，尽管后续居住地可以迁至巴厘岛。建议咨询官方民政局（Dukcapil）网站或法律专业人士，以了解配偶担保签证的最新具体文件要求。
✓ 1 条反馈 来自聊天群
规定根据《印度尼西亚公司法》（UU PT No.40/2007），董事和监事的任期限制为 5 年。未能及时更新董事会任命的公司将面临法律与人权部（AHU）的自动系统拦截。违规行为将导致董事个人承担责任，并限制对公司账户的操作权限。
✓ 1 条反馈 来自聊天群
步骤在印度尼西亚获取授权书，通常需要前往印度尼西亚大使馆或领事馆，这些机构通常位于雅加达。该服务不太可能直接在巴厘岛提供。请计划前往雅加达，并询问签发授权书的具体要求和流程。
✓ 1 条反馈 来自聊天群
案例外国人在巴厘岛获取驾照在技术上需要居留许可（KITAS）。在实践中，当地代理机构以约100美元的“捐款”服务来促进这一过程。由此产生的驾照是官方认可的，在区域内有效。
✓ 1 条反馈 来自聊天群
规定在印尼为在巴厘岛和爪哇岛使用而注册无人机可能很复杂。像sidopi这样的网站可能只服务于印尼公民。此外，有报道称在热门地点拍摄无人机的许可证费用非常高昂。
✓ 1 条反馈 来自聊天群
规定印度尼西亚正在从KBLI 2020过渡到KBLI 2025。该过渡必须在2026年6月18日之前完成。PT PMA（外资企业）实体必须核实其代码，因为代码拆分可能会触发新的投资要求或强制修改公司章程。
