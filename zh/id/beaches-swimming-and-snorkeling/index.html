印度尼西亚的海滩、游泳与浮潜：真正需要知道的事

简短回答
努沙杜瓦海滩状况多变，Mengiat、Geger、Melasti和Sanur等区域更适合游泳。若水质不佳，建议前往梦幻海滩或美拉斯蒂海滩，并可通过Surfline或Windy.app查看海浪预报。

来自真实经验

努沙杜瓦海滩的状况并不稳定，一些游客评价说那里俄罗斯游客拥挤，且海滩不如其他地方吸引人。有报告提到退潮、海浪以及可能存在大肠杆菌的问题。但大家的看法不一，也有人认为该地区很美，特别是在雨季观看日落时。有时建议前往梦幻海滩 (Dreamland) 或美拉斯蒂海滩 (Melasti) 以获得更好的体验。
✓ 1 条反馈 来自聊天群
对于在沙努尔（Sanur）遇到沙滩肮脏问题的游客，努沙杜瓦提供了显著更干净的水质和沙滩。努沙杜瓦的热门酒店包括 Merusaka 和 Ayodya，它们提供优质的海滩入口。通过 Agoda 或 Booking.com 预订时，这些热门地点经常显示库存不足。请注意，由于游客流量大，海滩俱乐部的食物供应可能在 14:00 前就会售罄。
✓ 1 条反馈 来自聊天群
巴厘岛努沙杜瓦的海浪情况：虽然 Conrad 酒店附近的部分海域浪大水浑，但 Bali Soul、Mengiat、Geger 和 Sawangan 等礁石区离岸较远的海域通常风平浪静，适合游泳。具体状况请查看 Surfline 或 Windy.app 的冲浪预报。
✓ 1 条反馈 来自聊天群
若想度过一个适合浮潜的安静假期，相比以派对闻名的吉利特拉旺安岛 (Gili Trawangan)，更推荐吉利艾尔岛 (Gili Air) 或吉利美诺岛 (Gili Meno)。努沙杜瓦 (Nusa Dua) 的浮潜条件并不突出。与喧闹的巴厘岛相比，吉利艾尔岛提供了更为宁静的环境。
✓ 1 条反馈 来自聊天群
努沙杜瓦及周边地区最适合游泳的海滩：如需寻找适合游泳的平静水域，可以考虑 Mengiat、Geger、Melasti 和 Sanur 海滩。艾湄（Amed）也因其宁静的水域而受到推荐。
