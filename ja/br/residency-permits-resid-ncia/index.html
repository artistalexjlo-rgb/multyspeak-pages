ブラジルの居住権（一時・永住）の取得：本当に知っておくべきこと

短い答え
ブラジルでの合法的な居住には、学生ビザやデジタルノマドビザ、家族再統合、不動産投資などの選択肢があり、各手段に応じた要件を満たす必要があります。市民権取得には通常1年以上の継続居住が必要で、書類のアポスティーユ認証や宣誓翻訳、最新の専門家による法的助言が不可欠です。

実際の経験から

「妊娠」以外の方法でブラジルへの合法的な居住を検討している方には、いくつかの選択肢があります。主な選択肢は以下の通りです。 1. 学生ビザ（VITEM IV）：語学コースやその他の教育プログラムに入学することで、一時滞在許可を得られる可能性があります。これには入学証明書と経済的能力の証明が必要です。 2. 難民ステータス：可能ではありますが、手続きは非常に長く複雑であり、連邦警察による決定には数年かかることもあります。適格基準や処理時間は様々で、厳格な報告義務が伴う場合があります。 3. デジタルノマドビザ（VITEM XIV）：リモートワークをしている場合、収入要件を満たせば、このビザで更新可能な期間、ブラジルに滞在できます。 4. その他のVITEM：資格や状況に応じて、仕事、家族再統合、投資などの他の一時滞在ビザが適用される場合があります。 移民政策は流動的であるため、公式情報源や移民弁護士に相談することをお勧めします。

ブラジルでの家族（義父や他の親族）の合法化、特にVNZH（一時滞在許可）や市民権取得プロセスを通じた手段を模索しています。議論されている重要な法的ポイントは、家族再統合を通じてVNZHを取得した人が、別の親族をスポンサーできるかどうかです。法律には、「スポンサーを受けた人」が「スポンサーになる」ことを禁じる条項が主たる移民法に明示されていない限り、それを禁じるのは違法であるという法解釈があります。子どもの一時的な市民権申請を通じて親を呼び寄せる、難民認定を求める、あるいはスポンサーである家族がブラジル市民権を取得するのを待つといった選択肢が検討されています。改姓による家族関係の証明の複雑さや、書類要件についても強調されています。
✓ 1 件の報告 チャットから
ブラジルの居住許可（Visto de Residência）を取得した後、市民権を申請するにはブラジルに1年間居住する必要があります。この1年間の期間中、最大90日まで国外へ出国することが許可されています。この90日間の不在期間も、市民権申請に必要な居住期間としてカウントされます。常に公式情報源や移民専門の弁護士に相談し、最新かつ具体的な法的アドバイスを得ることをお勧めします。
✓ 1 件の報告 チャットから
未成年者がブラジルで居住権を取得するための選択肢。言及されている最も速い方法は難民申請であり、これにより1年間有効な一時的RNM（全国移民登録）書類を取得できる場合があります。このステータスにはブラジル国外への渡航に関する条件があります。未成年者には一時的な保護者が任命される場合があり、学校への入学が必要となることもあります。母国での危険性を証明する必要があります。居住許可の取得は、会社を設立するための前提条件です。
✓ 1 件の報告 チャットから
ブラジルで出生証明書（特に古いソ連時代の文書）にアポスティーユを付与するには、まず現代版の複製（A4サイズ）を取得する必要があります。理論上はどの地域でもアポスティーユを申請できますが、行政上の慣行は異なり、地域の役所が管轄区域内で発行された文書のみを処理すると主張する場合があります。複製を取得するプロセスは、通常1〜2日かかります。
✓ 1 件の報告 チャットから
ブラジルの不動産を購入しても、自動的に市民権が得られるわけではない。不動産投資後に帰化（市民権）の資格を得るには、外国籍者は依然として一般的な居住要件を満たす必要があり、通常は申請前にブラジルに一定期間（一般的には8年間）継続して居住しなければならない。

ブラジルの永住権申請において、アポスティーユ認証が一般的に必要とされる書類は、出生証明書、ロシア（またはその他の国）の学歴証明書、結婚証明書です。すべての書類はポルトガル語に翻訳する必要があり、その翻訳はブラジル国内の宣誓翻訳者によって行われなければなりません。
✓ 1 件の報告 チャットから
ブラジルで出生による市民権を申請している人（外国人の両親の間にブラジルで生まれた子供）は、パスポートを待機する1年間の期間中、最長89日まで国外へ渡航できます。書類の全プロセスには1.5〜2.5年かかる場合があります。移民法の変更の可能性について最新情報を把握しておいてください。

ブラジルでの永住権は不動産購入を通じて取得可能です。過去の犯罪歴が抹消されていることが重要です。記録が抹消されていても、重大な犯罪であれば拒否される可能性があります。具体的な指針については、法律専門家や関連するコミュニティグループに相談することをお勧めします。
✓ 1 件の報告 チャットから
ブラジル市民権の取得や法的居住権の確立は、「出産ツーリズム」を通じない限り、長く困難なプロセスになる可能性があります。ブラジルでの出産は、親の市民権取得を早める手段として知られていますが、そうでなければ、法的地位を得るまでにはより長く複雑な道のりになることを覚悟してください。
✓ 1 件の報告 チャットから
ブラジルでの居住許可（VNH）を取得する場合、ロシアから取得したアポスティーユ付きの無犯罪証明書は90日間有効です。ロシアを出国し、この証明書の発行日から90日間の有効期間内にブラジルで居住許可申請書類を提出することが義務付けられています。それを過ぎると、新しい証明書を取得する必要があります。
✓ 1 件の報告 チャットから
ブラジルの永住権（Visto Permanente）を取得するためのコンサルティングサービスが利用可能です。手続きや要件に関する情報が必要な方は、申請をガイドしてくれる専門家を見つけることができます。
