SIMカードの購入と登録：ブラジルでは実際どう動いているか — 一次情報

短い答え
ブラジルでSIMカードを入手するには、CPFがなくてもパスポートで対応可能な大型ショッピングモールの通信キャリア公式店舗を訪れるのが最も確実です。物理SIMの購入が困難な場合は、登録の障壁が低いeSIMの利用を検討してください。

実際の経験から

ブラジルのSIMカードについて：1) CPFなしで物理SIMを入手することは可能ですが、店舗によって対応が異なります。2) 推奨される戦略：小さなサービスオフィスではなく、大型ショッピングモールや複数の通信会社を扱うキオスクを訪れるのが良いでしょう。3) Claroはプリペイドプラン（例：12GB/30日間で約40レアル）を提供しており、外国のパスポートで登録できる場合があります。4) eSIMの方が、CPFなしでの登録が容易な場合が多いです。
✓ 3 件の報告 チャットから
ブラジルでは、物理的なブラジルの身分証明書がない外国人が現地のSIMカードを入手するのは困難です。以下の選択肢があります。 1. 地元の居住者に頼んで、その人の名義でSIMカードを登録してもらう。これは成功例があり、無料で対応してくれることもあります。 2. 長期滞在の場合は、CPF（個人納税者番号）を取得し、自分でSIMカードを登録する。 3. あるユーザーから報告された回避策として、正規のCPFが拒否された後にオンラインで偽のCPFを生成し、SIMの有効化に成功した例がある。 4. eSIMを利用するのも便利な選択肢の一つです。
✓ 2 件の報告 チャットから
1. ブラジルの通信事業者（TIM、Vivo）は、ブラジル国外でローミング中にeSIMの初期アクティベーションを行うことを許可しておらず、端末が最初にブラジル国内のネットワークに接続する必要があります。 2. PicPayのようなデジタルウォレットやフィンテックアプリは、ブラジルの居住許可（VNJ/CRNM）を厳格に要求し、海外からCPFのみで登録しようとするユーザーを拒否します。 3. 以前は（一時的な「protocolo」を持つInfinityPayやBanco Rendimentoのように）完全な居住許可なしで登録できるプラットフォームもありましたが、これらは信頼性が低く、頻繁にポリシーが変更されます。
✓ 1 件の報告 チャットから
観光客がブラジルでSIMカードを購入する場合、路上のキオスクではなく、ショッピングモール内にある通信キャリアの公式店舗（Vivo、Claro）を利用してください。公式店舗であれば、CPFがなくても外国のパスポートでアカウントを登録できる場合があります。店舗で対応できない場合は、薬局チェーン（Pague Menosなど）でSIMを購入し、モバイルアプリ経由で自己登録するという選択肢もあります。サービス品質は場所によって大きく異なります。
✓ 1 件の報告 チャットから
リオデジャネイロのRioSulショッピングモール内にある新聞キオスクでは、CPFなしで物理的な観光用SIMカードを購入できます。パスポートの詳細を電話で英語対応のオペレーターに伝えることでカードが有効化されます。費用は70レアルと報告されています。SIM取得後、UberアカウントがCPFやクレジットカードを要求した場合、パスポート写真と自撮り写真による本人確認が必要になることがあります。
✓ 1 件の報告 チャットから
ブラジルで現地のSIMカード（Vivo、TIM）を購入するには、通常パスポートと多くの場合CPFが必要です。空港のキオスクでの有効化は時間がかかることがあり、公式店舗では電話越しに口頭確認が必要になる場合があります。プリペイドデータプランは広く利用可能ですが、地元のアプリ登録に必要な電話番号が含まれていない場合があります。
✓ 1 件の報告 チャットから
Vivoのモバイルサービスを利用するには、アプリをダウンロードするためにブラジルで登録されたアプリストアアカウント（Apple IDまたはGoogle Play）が必要です。これには通常CPF（納税者番号）が必要です。Vivo Easyプランは、ロシアでのローミング中にSMSを受信することはできません。
✓ 1 件の報告 チャットから
ブラジルでPIXに登録するためには、モスクワでCPFを取得済みの個人であれば、売店（キオスク）でPIXを購入できます。費用は約20米ドルです。店員と交渉すれば、アクティベート済みのSIMカードも一緒に入手できる場合があります。
