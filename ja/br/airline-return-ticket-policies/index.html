ブラジルのブラジル渡航時の復路航空券の要件：チャットからの実際の経験

短い答え
ブラジル渡航時は、往復航空券と全期間分のホテル予約確認書を必ず持参してください。特にターキッシュエアラインズは搭乗手続き時に厳格な書類チェックを行うため、提示できない場合は搭乗を拒否されるリスクが高いです。

実際の経験から

ターキッシュエアラインズでブラジルへ行く際は、厳しいチェックに備えてください。以下の提示を求められる可能性があります：1. 往復航空券（可能であれば同一予約のターキッシュエアラインズ便）。2. 滞在全期間のホテル予約確認書。3. 出国またはブラジル国内線の航空券。ターキッシュエアラインズは通常、支払い証明ではなく予約書類を確認します。これらの厳しい要件を満たせず、搭乗を拒否された旅行者の報告があります。
✓ 2 件の報告 チャットから
ブラジルへの渡航、特にターキッシュエアラインズを利用する場合、復路または第三国への航空券の提示を求められることがあります。これは、多くの国で観光客が滞在期間内（ブラジルの場合、ロシア市民は90日間など）に確実に出国するために課される一般的な要件です。エア・モロッコ、エチオピア航空、カタール航空などの航空会社は比較的寛容な場合もありますが、復路のチケットまたは第三国へのチケットを所持しておくことが推奨されます。オープンチケットや復路チケットがない場合でも、交渉の末に搭乗が許可される乗客（アジア系など）もいます。
✓ 1 件の報告 チャットから
ターキッシュ・エアラインズは、南米（サンパウロなど）へ渡航する乗客に対し、復路の航空券に関して厳格な要件を課しています。復路の航空券を所持していない場合、搭乗を拒否される可能性があります。他社便や第三国への復路便を受け入れる他の航空会社とは異なり、同社スタッフは、できれば同じ予約番号の下にあるターキッシュ・エアラインズ発行の復路航空券を頻繁に要求します。サードパーティの予約サイトで購入した航空券も完全に有効で、公式サイトで管理可能ですが、復路便の存在は不可欠です。
✓ 1 件の報告 チャットから
ブラジルの当局や航空会社は、入国時に帰国便のチケットの提示を求める場合があります。搭乗時の経験は様々で、チケットなしで搭乗を拒否された人もいれば、偽の予約で成功した人、全く確認されなかった人もいます。この要件は航空会社、出発地、個人の状況（荷物の量、家族旅行かソロかなど）によって異なります。帰国ルート上の経由地でビザが必要な場合、たとえ入国する意図がなくても、出発地で航空会社から確認されることがあります。
✓ 1 件の報告 チャットから
ターキッシュ・エアラインズは、イスタンブールからブラジルのサンパウロに向かう乗客に対して厳格な書類チェックを行っています。搭乗拒否のリスクを減らすため、乗客は以下のものを提示すべきです：1. 帰りの航空券、2. 予約済みのホテル宿泊確認書、3. 発展途上国ではない国（例：米国、英国、シェンゲン圏）の過去の査証（ビザ）は非常に有効です。これらのチェックは様々な国籍の乗客に適用されます。航空会社のスタッフに対しては、冷静かつ協力的な態度を保つことが推奨されます。
✓ 1 件の報告 チャットから
ドバイやアディスアベバ経由でブラジルに向かう旅行者は、出発空港での厳格な書類チェックを報告しています。往復航空券、ホテル予約、健康書類（黄熱病証明書など）の欠如が、搭乗拒否される標準的な理由です。復路のチケットとホテルの予約確認書は、必ず物理的なコピーを携帯してください。
✓ 1 件の報告 チャットから
ブラジルへの観光入国要件（ロシア国籍の場合）：有効なパスポートが必要です。入国時の金融証明やホテル予約の確認は入国審査官によって行われることはほとんどありませんが、航空会社（特にトルコ航空）は、搭乗の条件として往復航空券や次の目的地への航空券の提示を厳格に求めることで知られています。次の目的地へのチケットがない場合、搭乗拒否されるリスクがあります。
✓ 1 件の報告 チャットから
航空会社、特にターキッシュ・エアラインズは、強制送還者の責任を回避するために、ブラジル行きの便（GRU/GIG）で厳格な書類チェックを行っています。必要な書類には通常、復路の航空券、ホテルの予約確認書、場合によっては旅行保険が含まれます。これらが欠けていると、経由地で搭乗拒否される可能性があります。航空会社ごとの拒否率を調べておくことが推奨されます。
✓ 1 件の報告 チャットから
ロシアの国境警備隊は、通常ロシアへの入国時に復路の航空券を確認することはありません。しかし、渡航先の入国法に基づき、外国人の観光客が復路の航空券や第三国への航空券を所持していることを確認する責任は航空会社側にあります。ブラジルでは、オーバーステイを防ぐため、航空会社がこの要件を厳しくチェックしており、チケットを提示できない場合は搭乗拒否される可能性があります。
✓ 1 件の報告 チャットから
ブラジル行きの便を運航する航空会社は、チェックイン時に帰国便または次の目的地への航空券（ onward travel proof）を確認することがよくあります。復路の航空券がない場合、搭乗を拒否される可能性があります。いわゆる「ダミーチケット（未払いの予約）」を利用する旅行者も多いですが、航空会社スタッフに拒否されるリスクがあるため、入国トラブルを避けるには、検証可能な正規の航空券を用意することを推奨します。
✓ 1 件の報告 チャットから
ブラジル外務省は、経由地または帰りの航空券を所持することを推奨しています。常に提示を求められるわけではありませんが、航空会社や入国審査官はそれを要求する権利を留保しています。旅程の証明がない場合、搭乗を拒否される可能性があります。
✓ 1 件の報告 チャットから
カタール航空は、ブラジルへのフライトに搭乗する際、有効なブラジル居住許可証（VNJ）を所持しているか、または子供がブラジル市民であることを証明する書類を提示できる場合を除き、復路便または第三国への航空券の提示を厳格に義務付けています。
✓ 1 件の報告 チャットから
モスクワ（ドモジェドヴォ空港など）からブラジルのサンパウロへ飛行機で向かう乗客は、チェックイン時や搭乗時に帰りの航空券の提示を求められることがあります。提示できない場合、搭乗を許可されるためにその場で帰りの航空券を購入せざるを得なくなる可能性があります。
