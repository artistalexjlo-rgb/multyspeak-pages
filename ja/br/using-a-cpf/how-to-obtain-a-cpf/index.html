CPF（納税者番号）の取得方法：ブラジルでは実際どう動いているか — 一次情報

実際の経験から

CPF（個人納税者番号）は、ブラジルの多くのサービスに不可欠な現地税務識別番号です。日常の買い物は通常なしで行えますが、以下の場合は頻繁に必要になります：現地SIMカードの購入（大型ショッピングモールや外国人のための専門窓口が簡単）、特定のライドシェアアプリの利用（99など。Uberは国際クレジットカードで使える場合がある）、公共交通カードの取得（フロリアノポリスの観光用カードなどは例外）。パスポートを提示すればブラジル国内ですぐに（処理は15〜30分、発行は1〜3日）取得できます。到着前に大使館でCPFを取得するのは、データの誤りやサービス拒否の可能性があるため、問題になることがあります。

ブラジルへの短期滞在（例：1週間）の場合、現地システムを深く利用する予定がない限り、CPFの取得は必ずしも必要ではありません。ブラジル国外からのオンライン申請は通常うまくいかず、領事館や現地の窓口に行くよう誘導されます。国内線の航空券は、航空会社の公式サイト（例：Azul）で「estrangeiro（外国人）」を選択し、パスポート番号を使用することでCPFなしで購入できる場合があります。他のプラットフォームではCPFを要求されるか、なしでは手続きが難しく、第三者サイトで価格が高くなることがあります。最も確実なCPF取得方法は、ブラジルの連邦税務局の窓口へ直接行くことで、5〜7営業日、早ければ当日中に完了します。
✓ 2 件の報告 チャットから
現在、ブラジル国外にいる外国人が遠隔でCPF（個人納税者番号）を申請することはできません。ウェブサイト上ではその選択肢が表示されることがありますが、非居住者がオンラインで直接申請することは不可能です。現在の手続きでは通常、ブラジル国内の税務署、または自国のブラジル領事館を直接訪問する必要があります。必要な書類には、パスポート、申請書、航空券、出生証明書が含まれます。正確な手順や必要書類については、関係するブラジルの当局にあらかじめ確認することをお勧めします。
✓ 2 件の報告 チャットから
CPF（納税者番号）の申請プロセスが変更されました。以前は、モスクワのブラジル領事館でフォームに記入し、予約の招待を待つことで申請が可能でした。しかし、最近の情報では、モスクワの領事館はCPF申請のために就労ビザや学生ビザを求めているようです。代替手法：1. ブラジル国内で申請する：これが現在の主な手法です。ただし、短期滞在の観光客の場合、不要と判断されると拒否される可能性があります。しかし、適切な書類があれば取得可能です。2. 他国のブラジル領事館で申請する：これはあまり一般的ではなく、困難なオプションです。第3国の領事館は現地での居住（ビザや現地のIDなど）を必要とする場合があり、他国の観光客に対応しない可能性があるためです。あるユーザーはスリランカのブラジル領事館でCPFを取得したと報告しましたが、そのユーザーは居住ビザを所有していました。
✓ 1 件の報告 チャットから
ロシア市民がブラジルでCPF（個人納税者番号）を申請するための要件は複雑で変動的です。出生証明書のアポスティーユがCPF申請そのものには不要であるという情報もありますが、居住許可（VNH）の取得など、その後のプロセスで必要になる場合があります。最近の報告によると、オンライン申請の拒否率が高まっており、連邦歳入庁（Receita Federal）に行くよう指示されることが多いようです。オンラインや在外ブラジル大使館での申請では、出生証明書とその翻訳が求められる可能性があります。しかし、観光客がパスポートを持って直接歳入庁のオフィスに行く方が、手続きは簡単な場合があります。申請前に常に最新の要件を確認してください。
✓ 1 件の報告 チャットから
ブラジルでのCPF取得プロセスについて。一般的な手順は、オンライン申請、承認、対面訪問の予約、そしてその後の発行です。バリエーションがあり、メールでの書類提出で問題を報告するユーザーもいれば、アカウントを作成してFCPFコードを取得した後、オンラインポータルを使用して書類をアップロードすることに成功したユーザーもいます。連邦税務局への直接訪問も可能ですが、事前のオンライン予約が必要になる場合があります。CPFは紙またはデジタル形式で発行され、2021年以降はデジタル発行が主流となっています。ロシアで紙のコピーを受け取ったという報告もあります。
✓ 1 件の報告 チャットから
ブラジルに引っ越す際、別の州での短期滞在中にCPF（納税者番号）の申請を提出するのは避けてください（例：ジョアン・ペソアへ飛ぶ前の1〜2日間のサンパウロなど）。CPF登録は数日後にメールで最終番号を発行するため、一時的な州外の住所で登録すると、転居後に連邦データベースで同期エラーが発生し、CPFが一時的に読み取れなくなる可能性があります。最終的な目的地である都市で直接申請してください。
✓ 1 件の報告 チャットから
在モスクワ・ブラジル大使館でCPFを取得する場合、通常、申請者は申請の正当な理由を説明する必要があります。金融取引の開始、不動産の購入、その他CPFを必要とする法的手続きなどが共通の理由です。申請前に、大使館が必要とする書類と目的の記載について、特定の要件を確認することを推奨します。
✓ 1 件の報告 チャットから
CPF（個人納税者番号）発行に関する新しい規制により、子供であっても申請時に両親のCPF番号の提示が求められることが増えています。ブラジル国外の領事館（例：モスクワ）でCPFを取得するのは非常に困難になっており、現在はブラジル国内の連邦税務局（Receita Federal）の窓口で直接申請する方法が推奨されています。
✓ 1 件の報告 チャットから
ブラジルでCPF（納税者番号）を取得するには、パスポートを持って「Receita Federal（連邦税務局）」に行く必要があります。すぐに取得できたという報告がある一方で、オンライン申請や書類提出の際、署名の不備や自撮り写真の要件などで苦労する人もいます。官僚的な手続きの壁に備えておくことが賢明です。
✓ 1 件の報告 チャットから
ブラジルでのCPF登録には、現在、連邦税務局（Receita Federal）のオフィスへの対面訪問が必須です。オンラインや郵送での申請は頻繁に却下されるか、非常に厳格な条件下でしか処理されません。申請者は最初の申請を提出してから10日以内に直接出向く必要があり、そうでない場合は申請は自動的に取り消されます。
✓ 1 件の報告 チャットから
ブラジルでは、CPF（納税者番号）の登録は特定の住所に厳密に縛られるものではありません。外国籍者や観光客は、現地の連邦税務局（Receita Federal）で直接CPFを登録することができ、現地の銀行口座を開設する際には、旅行のルートに沿った別の住所を使用しても問題ありません。
✓ 1 件の報告 チャットから
非居住者は、トルコなどの大使館を通じてブラジルのCPF（納税者番号）を申請することはできません。このサービスは通常、その国の市民または合法的な居住者に限定されています。居住要件については、必ず各領事館の公式ウェブサイトを確認してください。
✓ 1 件の報告 チャットから
現在、ロシアに居住しながらブラジルの納税者番号（CPF：Cadastro de Pessoas Físicas）を取得することは不可能である。古い情報やAIが生成したアドバイスとは異なり、最近の申請はすべて拒否されている。
