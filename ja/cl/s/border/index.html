チリの出入国審査と入国管理：本当に知っておくべきこと

実際の経験から

リスク車でチリとアルゼンチンの陸路国境を越える際、通常は両国で入出国スタンプが押されますが、例外もあります。ルート（サンティアゴからメンドーサなど）によっては、アルゼンチン側のみで入国管理が行われ、チリの出国スタンプが押されない場合があります。また、通過を円滑にするための二国間協定により、アルゼンチンの国境職員がチリのツーリストカードを回収することもあります。スタンプ手続きが異なる可能性があることを想定しておいてください。
✓ 1 件の報告 チャットから
リスクチリの未成年者の出国規制は厳格です。18歳未満の未成年者がチリから一人で旅行する場合、親の同意は、単に市民権の国の基準ではなく、チリの現地規定に従う必要があります。航空会社は、10代の若者に対してはチケット購入時に手配しなければならない「同伴者なしの未成年者（menor no acompañado）」サービスを義務付けることがよくあります。他国で作成された標準的な公証書類は、チリの入国審査官に認められない場合があります。

事例サンティアゴへ飛行機で向かう際（特にトルコ航空でイスタンブール経由）、往復航空券の提示を求められることもあれば、求められないこともあります。チェックなしで通過する人もいれば、（特定の国籍グループなど）書類の提示を求められる場合もあります。これは、出国証明に関する航空会社や移民局の方針の運用が不一貫であることを示しています。
✓ 1 件の報告 チャットから
事例チリに入国する際、入国カードの訪問目的がバラバラになることがあります。グループで「vacaciones」（休暇）と記載されていても、個人の入国では何も聞かれずに「otros」（その他）となっていることがパタゴニアで観察されています。これは、他の要件さえ満たされていれば、訪問者の入国に影響しない移民局職員によるある程度の柔軟性や内部的な分類を示唆しています。
✓ 1 件の報告 チャットから
コツ片方の親のみとチリを旅行する未成年者の出国規定は一般的に寛容で、国境管理官が観光客に対してもう片方の親の同意書を厳格に求めることは多くありません。ただし、セキュリティのために公証役場で作成し、翻訳（英語またはスペイン語）した委任状を携帯することを強く推奨します。領事館では、ロシアの公証人データベースで確認済みの書類を印刷する手助けをしてくれる場合があります。

ルールイースター島の入国要件：1. 認可されたホテルを記載したオンラインフォームの完了（個人宅への滞在は制限されています）。2. 復路の航空券が必須。3. PDI（チリ到着時に提供される書類）は保管し、出国時に提示すること。サンティアゴからイースター島までのフライトは約4.5時間です。現地の天候は昼夜の温度差が小さいですが、紫外線が非常に強力です。
✓ 1 件の報告 チャットから
ルールチリ国籍の子供の場合、出国には親の同意が必須です。観光客として旅行する場合、同伴している親の同意があれば通常十分です。一部の航空会社は同伴していない親の同意を求めることがありますが、過去の旅行実績から、それが問題になることは少ないようです。チリ自体の出国政策は通常寛容です。
✓ 1 件の報告 チャットから
コツチリ入国時に発行されるTarjeta de Turismo（PDI）は、陸路の国境検問所（チリ・ボリビア国境やパタゴニアの国境など）では紙の原本が必要となることがよくあります。空港ではデジタル記録がある場合もありますが、出国時のスムーズな入国審査のため、入国時（国境や空港）に発行される紙の半券は保管しておくことを強く推奨します。
✓ 1 件の報告 チャットから
リスクチリ当局は、出生地主義による市民権取得に関して「通過旅行者」（観光客）という解釈を厳格化しています。近年の政策転換により、観光客として入国した親から生まれた子供の市民権に対する審査が厳しくなり、剥奪の可能性も出てきています。こうした「出産ツーリズム」モデルには遡及的な法的リスクが高いということが強調されています。
✓ 1 件の報告 チャットから
コツチリの観光ビザを90日間延長することは、特別な事情がない限り、ほとんどの観光客が利用できる手続きです。さらに、アルゼンチンなどの近隣諸国へのバスのチケットなど、出国を証明するものとして使える場合があります。現行の規定についてはチリの移民当局に確認することをお勧めします。
✓ 1 件の報告 チャットから
事例サンティアゴ国際空港に到着すると、入国審査官は通常、旅行者が宿泊するホテルの名前と滞在期間を尋ねます。トルコからの特定のグループの経験に基づくと、観光入国の場合、詳細な旅行計画や往復航空券の提示を求められることは通常ありません。
✓ 1 件の報告 チャットから
ルール16歳の未成年者がチリに入国する場合、チリの公式移民当局に特定の必要書類を確認してください。通常、片方または両方の親なしで旅行する未成年者は、不在の親からの公証済みの同意書、および出生証明書とパスポートのコピーが必要になる場合があります。
✓ 1 件の報告 チャットから
ルールイースター島（ラパ・ヌイ）へのアクセスは規制されています。旅行者は復路の航空券、宿泊証明（登録された観光プロバイダーの予約または住民からの招待状）、および搭乗前のFUI（単一入国フォーム）の記入を提示する必要があります。厳格な環境規制が適用されます。
✓ 1 件の報告 チャットから
コツチリに入国する際、入国審査官は通常、訪問の目的を尋ねます。観光客にとって一般的で受け入れられやすい回答は「Vacation（休暇）」または「Tourism（観光）」です。この簡潔な回答が入国手続きを円滑に進めるのに役立ちます。
