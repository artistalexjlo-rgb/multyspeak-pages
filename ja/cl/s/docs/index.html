チリの書類準備とサポート：本当に知っておくべきこと

実際の経験から

リスク子供が観光客としてチリに入国し、両親が（臨時または永住の）居住許可を持っている場合、子供の居住許可申請（「再統合」）のプロセスは複雑になることがあります。両親が臨時居住者の場合、特定の内部申請手続きが適用される可能性があります。パスポートと無犯罪証明書のみで「本人（titulares）」として2名で申請するほうが、片方を本人、もう片方を扶養家族として申請するよりも簡単な場合があります。後者の場合は宣言書やアポスティーユ付き雇用契約書などの追加書類が必要となり、アポスティーユ取得で課題が生じる可能性があります。
✓ 1 件の報告 チャットから
コツ購入領収書なしでチリで電話のIMEIを登録する場合、代替書類を使用できます。購入領収書の代わりに、PDI（調査警察）の入国記録や入国スタンプの写真が受け入れられる場合があります。ただし、要件は携帯電話事業者によって異なる場合があり、あるユーザーは詳細なしで「書類不十分」として却下された経験があります。承認の可能性を高めるために、PDI入国記録、パスポートのコピー、および入国スタンプの写真を提出することをお勧めします。
✓ 1 件の報告 チャットから
サービスロシアおよびCIS諸国の市民向けに、書類の公証、翻訳、アポスティーユ取得の代行サービスを遠隔で提供しています。ロシア連邦の書類（学歴、証明書、身分関係書類）のアポスティーユ（公証委任状の有無を問わず）、UAEやカタール等の領事認証、書類回収（無犯罪証明書は最短1日から）、身分関係書類の取得、82言語への公証認証付き翻訳サービスが含まれます。15分間の無料ビデオ相談が可能です。「Travelask experts」というキーワードと、書類のアポスティーユ・回収・翻訳に関するウェビナーについてお伝えください。初回無料相談はTelegram経由で受け付けています。
✓ 1 件の報告 チャットから
リスクチリの未成年者の出国規制は厳格です。18歳未満の未成年者がチリから一人で旅行する場合、親の同意は、単に市民権の国の基準ではなく、チリの現地規定に従う必要があります。航空会社は、10代の若者に対してはチケット購入時に手配しなければならない「同伴者なしの未成年者（menor no acompañado）」サービスを義務付けることがよくあります。他国で作成された標準的な公証書類は、チリの入国審査官に認められない場合があります。

手順チリのサンティアゴにあるロシア大使館で新しいロシアの国際パスポートを申請するには、申請書、旧パスポート、ロシアの国内パスポート、およびBanco de Chileでの支払い領収書を提出する必要があります。手続きには数か月かかることがあり、報告されている待ち時間は1.5か月から6か月ですが、約5週間で受け取った申請者もいます。必要書類と手順の最新リストについては、大使館の公式サイトを確認してください。
✓ 1 件の報告 チャットから
コツ片方の親のみとチリを旅行する未成年者の出国規定は一般的に寛容で、国境管理官が観光客に対してもう片方の親の同意書を厳格に求めることは多くありません。ただし、セキュリティのために公証役場で作成し、翻訳（英語またはスペイン語）した委任状を携帯することを強く推奨します。領事館では、ロシアの公証人データベースで確認済みの書類を印刷する手助けをしてくれる場合があります。
✓ 1 件の報告 チャットから
ルールチリで家族統合に基づく一時居住を申請する場合（例：チリ国籍者と結婚後）、通常、以下の書類が必要です：有効なパスポート、無犯罪証明書（翻訳・公証から60日以内の有効期間内であることを確認）、パスポートサイズの写真、婚姻証明書。居住許可の発行前に手数料が必要です。
✓ 1 件の報告 チャットから
ルールSERMIG（国立移民局）を通じたチリの移民手続きでは、ほとんどの書類はデジタルコピーのみで済みます。アポスティーユと宣誓翻訳が必要な必須書類は、無犯罪証明書（外国発行のもの）のみです。チリ大使館がこの書類の翻訳およびアポスティーユサービスを提供していることが多いです。必要書類のリストや提出については、SERMIGウェブサイトの公式「portal de trámites digitales」を利用してください。
✓ 1 件の報告 チャットから
ルールチリ国籍の子供の場合、出国には親の同意が必須です。観光客として旅行する場合、同伴している親の同意があれば通常十分です。一部の航空会社は同伴していない親の同意を求めることがありますが、過去の旅行実績から、それが問題になることは少ないようです。チリ自体の出国政策は通常寛容です。
✓ 1 件の報告 チャットから
コツチリ入国時に発行されるTarjeta de Turismo（PDI）は、陸路の国境検問所（チリ・ボリビア国境やパタゴニアの国境など）では紙の原本が必要となることがよくあります。空港ではデジタル記録がある場合もありますが、出国時のスムーズな入国審査のため、入国時（国境や空港）に発行される紙の半券は保管しておくことを強く推奨します。
✓ 1 件の報告 チャットから
ルールチリでチリ国籍者と結婚する外国人の場合、外国人配偶者は独身証明書を必要としません。チリ人配偶者は、オンラインで取得できる出生証明書のみが必要です。式典に必要な書類には、両配偶者のパスポート、空港で発行されたPDI（警察）の控え、2名の証人、および外国人がスペイン語を話せない場合は公認翻訳者が含まれます。
✓ 1 件の報告 チャットから
手順チリの移民庁（SERMIG）に書類を合法化する手順：1. 翻訳が公証または領事認証されていることを確認する。2. 外務省（MINREL）にて（翻訳を添付した）書類の合法化を行う。3. サービスは平日の14:00まで利用可能です。手続きを効率化するために、領事館で公証翻訳を提供できる場合があります。
✓ 1 件の報告 チャットから
手順Banco de Chileで領事手数料を支払うには、銀行の係員から番号札をもらってください（RUTがない場合はそれを使ってもらう可能性があります）。テーブルにあるピンクの振込用紙に記入し、現金で支払います。銀行が非顧客に通貨を両替しない場合があるため、正確な米ドル額を用意していくことをお勧めします。
✓ 1 件の報告 チャットから
ルール16歳の未成年者がチリに入国する場合、チリの公式移民当局に特定の必要書類を確認してください。通常、片方または両方の親なしで旅行する未成年者は、不在の親からの公証済みの同意書、および出生証明書とパスポートのコピーが必要になる場合があります。
✓ 1 件の報告 チャットから
ルールイースター島（チリ）での自動車のレンタカー要件：標準的な各国の運転免許証（ロシアのものを含む）は通常、レンタカーに利用できます。現在の旅行者から、追加の国際免許証の要件は報告されていません。
✓ 1 件の報告 チャットから
ルールチリで婚姻届を提出するには、有効なパスポートまたはチリのCédula（IDカード）が必要です。最初のプロセスにおいて、これ以外に追加の書類が必要であるという報告はありません。
