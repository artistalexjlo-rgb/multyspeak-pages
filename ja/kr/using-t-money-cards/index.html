韓国のT-Moneyカードの利用：チャットからの実際の経験

短い答え
韓国の公共交通機関には、全国で使えるT-moneyカードが不可欠であり、コンビニや駅で購入・チャージが可能です。子供連れの場合は、パスポート等を提示して子供用の割引設定を行ったカードを各人分用意してください。

実際の経験から

韓国での公共交通機関には、特に子供連れの場合、T-moneyカードを推奨します。T-moneyカードはコンビニ（セブン-イレブン、CU、GS25）や駅、空港の自動券売機で購入・チャージできます。子供用の割引運賃も用意されており、年齢基準を満たしていればその設定にする必要があります。Wowpassは使えますが、T-moneyカードの子供用設定やチャージはできません。子供用カードは券売機かコンビニのレジでチャージできます。多様なデザインのカードが販売されています。
✓ 3 件の報告 チャットから
韓国の決済システム：WOWPASSは、デビットカードとT-money（交通カード）が一体になったものです。多くのバスが完全キャッシュレス化に向かっているため、公共交通機関（バス、地下鉄）を利用するにはT-moneyカードが不可欠です。T-moneyはコンビニ（GS25、CU、セブンイレブン）や地下鉄駅のキオスクで購入・チャージが可能です。正しい運賃計算と乗り継ぎ割引を受けるため、バスに乗降する際は必ずカードをタッチしてください。
✓ 3 件の報告 チャットから
韓国で子供と一緒にWowpassなどのトラベルカードを利用する場合、公共交通機関（地下鉄とバス）には一人ずつ別々のカードが必要です。これは、通常乗車時と降車時の両方で料金が引き落とされるためであり、子供料金が異なる場合があるからです。バスの運転手と交渉して1枚のカードで済ませられる場合もありますが、確実な方法ではありません。そのため、子供用の交通カードを個別に購入する必要があります。
✓ 2 件の報告 チャットから
WOWPASSは多機能型プリペイドカードです。決済用のメイン残高と、公共交通機関用のT-money残高が独立しています。交通費を支払うには、WOWPASSアプリ、またはコンビニ（セブンイレブン、GS25、CU）や地下鉄駅にある専用端末からT-money残高をチャージする必要があります。バスや地下鉄の改札では、カードを読み取り機にかざして利用します。
✓ 2 件の報告 チャットから
韓国の公共交通機関、特にソウルの地下鉄は平日午前5時30分から午前1時まで、週末は午前0時まで運行しており、駅ごとの運行スケジュールは地図アプリで確認できます。バスも一般的な交通手段です。地下鉄やバスを円滑に利用するにはT-moneyカードが不可欠で、Wowpassアプリやコンビニ（CU、GS25、7/11）でチャージ可能です。Wowpassカード自体も決済手段かつ交通カードとして機能します。済州島では公共交通機関の運行頻度が低いため、レンタカーやタクシーの方が実用的ですが、費用は高くなる可能性があります。済州島のタクシー料金はソウルと同水準ですが、島内の移動距離が長いため、1回あたり4万〜5万ウォンかかることがあります。
✓ 1 件の報告 チャットから
仁川での公共交通機関については、コンビニでT-moneyカードを購入し、チャージすることをお勧めします。よく推奨されるのは、交通カードと銀行カードの両方の機能を持つWowpassです。アプリ経由でWowpassに資金をチャージし、交通セクションへ送金できます。各人が自分専用の交通カードを持つ必要があります。仁川空港から市内中心部までの料金は、一般列車で約5,350ウォン、直通列車で約11,600ウォンです。片道切符も券売機で購入可能です。
✓ 1 件の報告 チャットから
ソウルと釜山の公共交通機関は、チャージ式カードか、片道切符を利用します。ソウルでは、片道切符は券売機で購入でき、システムから出る際に500 KRWのデポジットが返金されます。券売機で一度に購入できるのは5枚までで、特定の駅がリストにない場合は地図から選択できます。釜山では券売機がより高速で、QRコード付きの切符が発行されますが、デポジットの返金システムはすべての駅にあるわけではない可能性があります。

韓国のバス料金は、支払い方法（交通カードか現金か）により通常700〜1600ウォンです。6歳未満の子供は交通カード利用で無料です。6歳〜18歳の子供については、チャージ場所でパスポートを提示することで、T-moneyカードに青少年料金を適用できます。バスの乗り継ぎは30分以内であれば、通常1回の運賃で済みます。地下鉄運賃は少し高く、約1550ウォンです。

Namaneカードは韓国で一般的な交通カードとして機能しますが、Discover Seoul Passのような観光特典はありません。クライメートカードはソウル専用の乗り放題パスです。T-moneyは汎用的な交通カードで、個別にチャージが必要です。韓国の銀行口座を保有している場合、銀行口座と連動した交通カードを使えば、都度チャージではなく月ごとの引き落としが可能になる場合があります。

韓国の空港リムジンバスは、T-Moneyカードまたは現金で支払えます。Wowpassの残高をそのまま使おうとする旅行者もいますが、バスの端末では信頼性が低いため、T-Money機能を使うか現金を用意しておくことをお勧めします。

韓国の公共交通機関：地下鉄の利用には、子供一人ひとりに対してT-moneyカードが必要です。子供用運賃の割引を適用するには、地下鉄駅の有人窓口を訪れ、子供のパスポートや身分証明書を提示して生年月日を登録する必要があります。

韓国では子供の場合、ソウルエリア限定のClimate CardよりもT-Moneyカードの方がコスト効率が良いです。T-Moneyカードは子供向け運賃割引があり全国で使用できますが、Climate Cardはソウル市内のみに限定されています。
