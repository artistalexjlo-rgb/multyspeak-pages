インドネシアのIMEI登録ガイド：チャットからの実際の経験

短い答え
インドネシアで現地SIMを継続利用するには、端末のIMEI登録が義務付けられています。空港での入国時、またはTelkomsel等の公式ショップで登録を完了してください。

実際の経験から

インドネシアを訪れる外国人観光客は、モバイル端末のIMEI登録要件に直面します。オプションには以下があります：1) Grapari Telkomselオフィスで登録する（3か月有効）、2) 税関で登録税を支払う、3) 既にIMEIが登録済みの現地端末を購入する、4) 入国後に税金を支払って割引を受ける。通信サービスを確実に機能させるには登録が必要です。
✓ 4 件の報告 チャットから
インドネシアのSIMカードは、最初に登録した端末のIMEIに紐付けられます。有効化したSIMを別の端末で使いたい場合は、その端末のIMEIもインドネシア当局に登録する必要があります。未登録の外国製端末は一定期間（約3ヶ月）経つとSIMがブロックされる可能性があります。IMEI登録は、入国時の空港または公式の通信事業者ショップで行えます。
✓ 3 件の報告 チャットから
インドネシアでは、90日以上滞在する端末のIMEI登録が義務付けられています。空港（税関）で登録していない場合、SIMカードが30日後にブロックされる可能性があります。その場合は、パスポート、ビザ、航空券を持って税関事務所（Bea Cukai）や認定された通信事業者の支店を訪れてください。端末の状態は政府の公式IMEIポータル（imei.kemenperin.go.id）で確認できます。
✓ 1 件の報告 チャットから
90日以上インドネシアに滞在する外国人は、現地SIMカードを使用するために携帯電話のIMEIを登録する必要があります。500ドル以下の端末（輸入関税免除）であれば、空港での登録は無料です。Telkomselのオフィスでは、SIM購入時に3ヶ月間のIMEI登録が可能です。一度も登録せずに現地のネットワークに90日間接続されると、すべてのインドネシアのSIMカードが使用不能になります。
✓ 1 件の報告 チャットから
インドネシアで長期間使用するモバイル端末には、IMEI登録が必要です。ブロックされた端末への対策としては、現地で電話を購入する、別のキャリアを使用する（IMEIデータベースが共有されていない場合）、または到着時に税関で関税を支払うといった方法があります。単にSIMカードを交換しても、ハードウェアレベルのIMEIブロックを回避することはできません。
✓ 1 件の報告 チャットから
インドネシアに長期滞在する外国人は、携帯電話のIMEIを登録する必要があります。500ドルの免税を受けるには、到着時に空港の税関エリア内で登録を完了しなければなりません。登録前に到着エリアから出てしまうと、手続きが著しく困難になります。
✓ 1 件の報告 チャットから
海外製スマートフォンのIMEIは、現地SIMカードを購入する際、空港や公式ショップで無料で登録できます。現地SIMを正常に機能させるには登録が必要です。
