渡航書類の準備：インドネシアでは実際どう動いているか — 一次情報

実際の経験から

ルール2026年6月1日より、すべてのインドネシア企業（PT）は、SABH/AHUシステムを通じて司法省に年次報告書を提出することが義務付けられました。2025会計年度の期限は2026年6月30日です。非準拠の場合は書面による警告があり、AHUシステムへのアクセスが停止される可能性があるため、会社構造や取締役の変更ができなくなります。要件には、財務諸表、活動報告書、CSR報告書（資源セクター）、監督報告書、および取締役・コミッショナーの給与データが含まれます。
✓ 1 件の報告 チャットから
ルール家族用KITAS（配偶者がインドネシア市民）の場合、プロセスには通常、配偶者のKTP（IDカード）の登録地に基づいたSKTT（居住証明書）の取得が含まれます。配偶者のKTPがジャカルタで登録されている場合、最初の登録をそこで行う必要があるかもしれませんが、その後バリ島に移住可能です。配偶者スポンサービザの最新の必要書類については、Dukcapil（市民登録所）の公式ウェブサイトや法律専門家に相談することをお勧めします。
✓ 1 件の報告 チャットから
ルールインドネシアの会社法（UU PT No.40/2007）に基づき、取締役および監査役の任期は5年に制限されています。役員の再任手続きを怠った企業は、法務人権省（AHU）により自動的にブロックされます。不履行の場合、取締役は個人的な賠償責任を負い、法人口座へのアクセスが制限されます。
✓ 1 件の報告 チャットから
手順インドネシアで委任状を取得するには、一般的にジャカルタにあるインドネシア大使館か領事館へ行く必要があります。バリ島で直接このサービスを受けられる可能性は低いです。ジャカルタへ移動する計画を立て、委任状発行のための具体的な要件や手順を問い合わせてください。
✓ 1 件の報告 チャットから
事例外国人のバリ島での運転免許証取得には、技術的には居住許可（KITAS）が必要です。実際には、地元の代理店が約100ドルの「寄付」サービスとして手続きを代行しています。発行された免許証は公式に認められており、地域内での移動に有効です。
✓ 1 件の報告 チャットから
ルールバリ島やジャワ島で使用するためのドローン登録は複雑な場合があります。sidopiのようなウェブサイトはインドネシア国民専用の場合があります。さらに、人気の撮影スポットではドローン撮影許可に多額の費用がかかるという報告もあります。
✓ 1 件の報告 チャットから
ルールインドネシアでは、KBLI 2020からKBLI 2025への移行が進められています。この移行は2026年6月18日までに完了しなければなりません。PT PMA（外国投資会社）は、コードの分割が新たな投資要件や定款変更の義務化につながる可能性があるため、自社のコードを照合する必要があります。
