インドネシアの出入国審査：チャットからの実際の経験

実際の経験から

手順海外へ渡航する18歳未満の単独旅行者（アンコンパニード・マイナー）の手続きについて：エミレーツ航空やカタール航空などの大手航空会社は、公式の「アンコンパニード・マイナー（同伴者のいない未成年者）」サービスを提供しています。このサービスを航空会社から直接予約することを強く推奨します。これにより、地上および機内での監督が保証され、書類や空港の入国管理手続きにおける問題を軽減できます。
✓ 1 件の報告 チャットから
リスクインドネシアへ向かう航空会社は、外国人旅行者に対して帰国用または出国用の航空券を厳しくチェックすることが多いです。インドネシアからの出国証明がない場合、航空会社は強制送還のコストを負担する責任を負うため、有効なチケットが提示されるまで搭乗が拒否されます。
✓ 1 件の報告 チャットから
ルールインドネシアへの渡航途中でシンガポールを経由する場合、通過要件（通常96時間の通過ビザ免除）を満たしていれば、個別のシンガポールビザは不要です。最終目的地への航空券を印刷して持参し、出発地の空港でチェックインする際に航空会社にビザ要件を確認することをお勧めします。
✓ 1 件の報告 チャットから
リスクジャカルタ（CGK）第3ターミナル経由でバリ島へ向かう場合、1時間35分の乗り継ぎは非常に危険です。荷物が最終目的地までスルーチェックインされていても、最初の入国地点であるジャカルタでインドネシアの入国審査と税関を通過し、国内線ターミナルへ移動する必要があります。最低でも2.5〜3時間の乗り継ぎ時間を確保することをお勧めします。
✓ 1 件の報告 チャットから
リスクインドネシアの入国管理局は、コンテンツクリエイターに対するビザ規定の遵守を厳しく取り締まっています。観光ビザでの商業活動（ブランドコラボレーション、宿泊とのバーター、報酬を伴う撮影など）は違法であり、強制送還の対象となります。現在、コンテンツクリエイター向けの特定のビザカテゴリーが検討されています。
✓ 1 件の報告 チャットから
ルールインドネシアの到着ビザ（VOA）は30日間有効で、さらに30日間の延長が可能です。30日を超えて滞在する旅行者は、合計滞在期間（例：45日間）に合わせた出国航空券を提示することができます。入国審査官はビザの延長が可能であることを知っているため、通常はこれを受け入れます。
✓ 1 件の報告 チャットから
ルール2026年7月1日より、インドネシアではすべての新規SIMおよびeSIM登録に生体認証（顔認証）が義務付けられます。この要件は地元住民と外国人観光客の両方に適用され、システムが入国管理データベースと照合して本人確認を行います。
✓ 1 件の報告 チャットから
手順インドネシアに到着する旅行者は、電子税関申告書（ECD）を完了する必要があります。到着の3日以内のオンライン入力が推奨されます。完了するとQRコードが生成され、入国時に税関職員へ提示する必要があります。
✓ 1 件の報告 チャットから
ルールバリ空港（ングラ・ライ国際空港）の待ち時間は予測できず、40分から2時間かかることもあります。出発時は十分に時間に余裕を持ってください。
