ブルガリアの書類準備とサポート：本当に知っておくべきこと

実際の経験から

ルールブルガリア市民は、有効期限が間近であっても、有効なパスポートまたは国民IDカード（lichna karta）を使用してEU内を移動できます。重要な要件は、旅行時に書類が期限切れになっていないことです。長期計画用に10年有効なパスポートも利用可能です。
✓ 2 件の報告 チャットから
リスクブルガリアでは、2015年以降、10,000 BGN（約5,000ユーロ）を超えるすべての不動産取引は、法的に銀行振込で行うことが義務付けられています。このような金額の現金支払いは違法です。契約上の不動産価格を過少申告し、差額を現金で支払うようなスキームに関与することは違法であり、取引が無効とされる可能性があります。ロシアの税務当局（FNS）は、不動産販売に関連する未申告の外国現金取引に対して最大40%の罰金を科すことができます。
✓ 1 件の報告 チャットから
手順民法契約（GPD）に基づいて働いている場合の、ビザ申請書の「雇用者」欄の記入方法を解説します。職位には「請負人」、「フリーランサー」、または「コンサルタント」と記載し、雇用者名には契約先の企業名を記載することを推奨しています。また、2-NDFL証明書（該当する場合）などの裏付け書類を添付することに言及し、領事館は契約の種類そのものよりも、所得の安定性と出所の明確さを重視していることを強調しています。
✓ 1 件の報告 チャットから
手順個人事業主（IP）がビザを申請する場合の必要書類：1. EGRIP（個人事業主統一国家登録簿）からの抽出物、2. 税務登録証明書、3. 年金基金登録証明書、4. 電子版労働手帳の写し（10年分）、5. 直近6ヶ月間の銀行取引報告書、6. 年金基金への寄付証明書。ほとんどの書類はGosuslugiポータルから印刷可能です。
✓ 1 件の報告 チャットから
コツロシア市民とブルガリア市民の婚姻届のためにソフィアで医療書類を早急に入手する必要がある場合、有料のクリニックをお勧めします。「Torax」というクリニックが候補として挙げられます。具体的なサービス内容や期限についてはウェブサイトで確認してください。ブルガリア市民が自身の主治医を訪ねる必要があるのか、それとも私立クリニックを利用できるのかは不明です。
✓ 1 件の報告 チャットから
手順EU圏外からブルガリアにペットを連れて行くための要件：1. 国際獣医パスポート。2. マイクロチップ。3. 有効な狂犬病ワクチン接種。4. 狂犬病抗体価検査（旅行の少なくとも3ヶ月前に行うこと）。5. 地元の獣医当局が発行するF1証明書（国境や空港でEU健康証明書と交換）。
✓ 1 件の報告 チャットから
手順モスクワでのブルガリアのビザ状況を問い合わせる際は、infomos@bul.com、Embassy.Moscow.bg、secretary.ruに同時にメールしてください。書類提出日、パスポート通りのフルネーム、パスポート番号を記載してください。回答は通常2〜3営業日以内に期待できます。家族再会ビザ（Dタイプ）については、正式な居住許可のみが必要であり、財政証明や住居証明は不要です。
✓ 1 件の報告 チャットから
手順ブルガリアのビザ申請書を記入する際、「主婦」や「無職」、「個人事業主」、または特定の職業といった職業に関する質問については、ビザセンターに確認をとるべきです。代替の回答を用意しておくか、正確なガイダンスを受けるためにビザセンターのスタッフに相談することをお勧めします。
✓ 1 件の報告 チャットから
ルール16歳以上のウクライナ市民は、保護者の同意なしで単独でブルガリアに渡航できます。ロシア市民の場合は、公証された保護者の同意書を携行することを推奨します。ブルガリアの国境での取り締まりは一般的に寛容ですが、未成年者の渡航には標準的な予防書類として役立ちます。
✓ 1 件の報告 チャットから
ルール子供が片方の親のみと旅行し、もう片方の親が同行せず、かつ子供が物件所有者でない場合、通常は旅行しない親からの公証済みの同意書が必要です。物件所有者の配偶者が旅行する場合、特定の同意は通常必要ありません。
