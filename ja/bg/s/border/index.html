ブルガリアの国境・入国管理：本当に知っておくべきこと

実際の経験から

ルールブルガリア市民は、有効期限が間近であっても、有効なパスポートまたは国民IDカード（lichna karta）を使用してEU内を移動できます。重要な要件は、旅行時に書類が期限切れになっていないことです。長期計画用に10年有効なパスポートも利用可能です。

リスクブルガリアのシェンゲン圏入りに伴い、入国スタンプの運用に一貫性がありません。自動EESシステムの統合が進められていますが、国境検問所、個々の職員の習慣、またはパスポートの種類（生体認証パスポートなど）に応じて、手動のスタンプが頻繁に行われています。居住許可保持者は、滞在許可証の更新など、地元の移民局が証明を求めることが多いため、必要な場合は行政手続きのために先制的に入国スタンプを要求することを強くお勧めします。
✓ 1 件の報告 チャットから
事例ブルガリアの居住許可証（カード）の更新に最適な申請時期については情報が錯綜しています。ブルガスの移民局から「カード有効期限の1ヶ月前から14日前までの間に申請するように」と助言を受けたという人がいる一方で、3ヶ月前から申請可能という意見もあります。ただし、後者の場合は新カードの有効期間が申請日から開始され、以前のカードの残りの有効期間が切り捨てられる可能性がある点に注意が必要です。

ルールイスタンブール空港からブルガスへのバス旅行：所要時間は2つの国境通過を含め約5時間です。主要バス会社：Arda-Tur、Nishikli、Metro。チケットはobilet.comで確認可能ですが、すべての運送会社が掲載されているわけではありません。一部の時刻表は中央バスターミナル（Otogar）でのみ入手できます。支払いなしでの予約は通常不可能です。Otogarの窓口番号は反時計回りに割り振られており、キオスクには運送会社名が明記されています。
✓ 1 件の報告 チャットから
コツ1回入国型のブルガリア・シェンゲンビザがあれば、旅行者はブルガリアに入国した後、空路や陸路で他のシェンゲン協定国（ハンガリー、オーストリア、ギリシャなど）へ移動できます。シェンゲン圏内の国境では通常、パスポート管理がないためです。出身国（ロシアなど）への帰国は、必ずしもブルガリアからである必要はなく、ギリシャなどどのシェンゲン協定国から出国しても構いません。
✓ 1 件の報告 チャットから
コツブルガリアのシェンゲンビザを保持している場合、シェンゲン圏への最初の入国をブルガリア経由で行うことは厳密には義務ではありません。最近のユーザーの経験によると、ブルガリアに先に入国せずに他のヨーロッパ諸国へ旅行しても、その後のビザ申請に悪影響はありませんでした。これは、厳格な「初回入国ルール」という一般的な誤解と矛盾します。
✓ 1 件の報告 チャットから
ルール16歳以上のウクライナ市民は、保護者の同意なしで単独でブルガリアに渡航できます。ロシア市民の場合は、公証された保護者の同意書を携行することを推奨します。ブルガリアの国境での取り締まりは一般的に寛容ですが、未成年者の渡航には標準的な予防書類として役立ちます。
✓ 1 件の報告 チャットから
ルールブルガリアのVNJ（居住許可）の更新を申請する場合、現在のVNJカードは没収されず、有効なままとなります。申請者は、VNJカードに記載されている有効期限までは、そのカードを使用してブルガリアを出国し、再入国することが許可されています。
✓ 1 件の報告 チャットから
ルールブルガリアのシングルエントリービザでのシェンゲン圏内の移動は許可されています。シェンゲン圏内のフライトには通常パスポートコントロールはありませんが、潜在的な国境検査に対応するため、ブルガリアへの先の旅程を証明する書類を携行すべきです。
✓ 1 件の報告 チャットから
コツブルガリアの国家ビザの有効期限が7月8日の場合、その日は有効期間内に含まれるため、7月8日にブルガリア・トルコ国境を合法的に越えることができます。念のため、7月7日に出国することも可能です。
✓ 1 件の報告 チャットから
コツブルガリア・トルコ国境では、徒歩での入国の方が概して速く、約15分かかると報告されています。歩行者は車両交通とは別の列や通路を使用するため、自動車用の書類窓口を避けることができます。

リスクブルガリアの永住権（PMP）保持者は、ステータスを失うリスクなしに、12ヶ月を超えて連続して出国することはできません。
