브라질 환승 시 수하물 등록 규정: 채팅방에서 나온 실제 경험

짧은 답
상파울루 GRU 공항에서 별도의 항공권으로 환승할 때는 수하물을 직접 찾고 입국 심사 후 다시 위탁해야 합니다. 환승 시 터미널 간 이동은 도보로 10~20분 정도 소요되며, 수하물 재위탁 가능성을 고려해 4~6시간 이상의 넉넉한 여유 시간을 권장합니다.

실제 경험에서

GRU 공항(상파울루)에서 국제선과 국내선을 연결할 때: 터미널 3(국제선)에 도착하여 여권 심사를 마치고 짐을 찾은 후 터미널 2(국내선)로 이동하여 재체크인 및 보안 검색을 하십시오.
때로는 터미널 3 근처에서 국내선 짐을 부칠 수 있는 경우도 있지만 직원의 가용성에 따라 다릅니다. 승객들에게 도움을 요청하도록 조언하십시오: "Please help me"(영어) 또는 "Por favor me ajude"(포르투갈어). 브라질 사람들은 대체로 친절합니다.
✓ 1 건의 후기 채팅방에서
리마에서 모스크바로 가는 단일 항공권으로 상파울루에서 3시간 환승 시 항공사가 바뀌는 경우(예: 라탐에서 카타르 항공), 수하물을 다시 위탁할 필요는 없습니다.
위탁 수하물은 보통 최종 목적지까지 직접 연결됩니다. 혼란을 피하기 위해 특히 새로운 규정 변경 가능성을 들었다면 항공사에 직접 확인하는 것이 좋습니다.
✓ 1 건의 후기 채팅방에서
상파울루 과룰류스 공항(GRU)에서 3터미널(국제선)과 2터미널(국내선)을 환승하는 승객은 동일 예약 항공권이라 하더라도 일반적으로 수하물을 찾아 세관을 통과한 후 국내선 항공사 카운터에서 다시 부쳐야 합니다.
단, 단일 항공권으로 국제선에서 국제선으로 환승하는 경우는 예외적으로 수하물을 최종 목적지까지 연결할 수 있습니다.
✓ 1 건의 후기 채팅방에서
상파울루 과룰류스(GRU) 공항에서 별도의 항공권으로 환승할 경우, 2터미널에서 3터미널까지는 도보로 약 10분이 소요됩니다.
4시간 정도의 환승 시간(예: 18:20 도착, 22:20 출발)이면 일반적으로 충분하지만, 큰 지연이 없다면 2시간도 가능합니다. 수하물 수취에 시간이 걸릴 수 있습니다. 환승 시간이 촉박한 경우 도착 시 공항 직원에게 알리는 것이 좋습니다.
✓ 1 건의 후기 채팅방에서
상파울루(GRU) 공항에서의 환승은 같은 항공권으로 예약된 경우 2시간 이내에도 가능합니다.
공항 구조상 환승 승객을 효율적으로 관리하며, 대기 시간이 짧은 승객을 안내하는 경우가 많습니다. 그러나 항공권을 따로 예약했을 경우에는 도착 항공편의 지연이나 수하물 재위탁 가능성을 고려하여 6시간 이상의 여유를 권장합니다.
✓ 1 건의 후기 채팅방에서
과룰류스 공항(GRU)에서 GOL 항공으로 국내선에서 국제선으로 환승할 경우, 처음 체크인 카운터에서 수하물이 최종 목적지까지 연결되는지 확인하세요.
1시간 45분의 환승 시간은 촉박합니다. 수하물을 다시 부쳐야 할 경우를 대비해 4시간 정도의 환승 시간을 권장합니다.
✓ 1 건의 후기 채팅방에서
브라질 내 연결 항공편의 경우, 두 항공편이 하나의 예약으로 되어 있다면 위탁 수하물은 일반적으로 최종 목적지까지 이동하며, 특히 상파울루와 같은 도시를 경유하여 환승 지점에서 입국하지 않는 경우 직접 찾을 필요가 없습니다.
✓ 1 건의 후기 채팅방에서
상파울루 GRU 공항에서 서로 다른 항공사나 별도의 국제선 티켓을 이용하는 승객은 터미널을 환승하더라도 반드시 브라질 입국 심사와 세관을 거쳐야 합니다.
연결되지 않은 예약 건에 대해 공항 내부 환승 구역(Airside)을 이용한 직접 환승은 불가능합니다.
✓ 1 건의 후기 채팅방에서
브라질에서 항공편을 환승할 때는 수하물 태그에 적힌 최종 목적지 코드를 확인하십시오.
항공사가 다르거나 인터라인 협정이 없는 경우, 승객은 중간 공항에서 수하물을 찾고 입국 심사를 거친 뒤 다음 항공편을 위해 다시 체크인해야 합니다.
✓ 1 건의 후기 채팅방에서
상파울루(GRU)에서 별도의 항공편으로 연결하는 승객은 수하물을 찾아서 다시 부쳐야 하는 경우가 많습니다.
터미널 간 이동은 도보(약 15-20분 소요) 또는 초록색 무료 셔틀버스를 이용할 수 있습니다.
